# Дизайн-спецификация: Конструктор и каталог пользовательской арматуры (Custom Valve Families & Parametric Editor)

## 1. Введение и цели

В инженерной практике при проектировании технологических трубопроводов, систем отопления, водоснабжения и вентиляции постоянно возникают потребности в специализированных элементах арматуры:
- Антивибрационные клапаны / виброкомпенсаторы (требующие волнистых или зигзагообразных разделителей, штриховок или маркеров «АВ»).
- Задвижки и шаровые краны с электроприводами (AUMA, ГЗ и др. — с буквой «Э» в квадрате на 2D-чертеже и коробчатым блоком привода в 3D).
- Мембранные регулирующие клапаны и редукторы давления (с «тарелкой» мембранного исполнительного механизма МИМ и буквой «М»).
- Обратные клапаны со сплошной заливкой входного треугольника по направлению потока (по ГОСТ 21.205 / ГОСТ 2.785).
- Предохранительные клапаны с пружинным колпаком и боковым сбросом.

**Цель:** Создать масштабируемую подсистему пользовательских семейств арматуры (`CustomValveDefinition`), позволяющую инженеру без изменения исходного кода создавать, редактировать, настраивать графику 2D УГО (заливки, штриховки, значки штока/привода) и параметры 3D-тела с живым предпросмотром и автоматической интеграцией в спецификации и экспорт DXF.

## 2. Архитектура моделей данных

### 2.1 Перечисления стилей 2D-символа
```dart
/// Стиль заливки крыла (треугольника) корпуса арматуры в 2D
enum ValveWingFillStyle {
  /// Контурный (белый непрозрачный фон с цветной обводкой)
  outline,

  /// Сплошная заливка цветом системы / слоя
  solid,

  /// Диагональная штриховка под 45 градусов
  hatched,

  /// Перекрестная сетчатая штриховка
  crossHatched,
}

/// Внутренний центральный разделитель / знак затвора
enum ValveDividerType {
  /// Без разделителя (вершины треугольников сходятся в точке)
  none,

  /// Вертикальная разделительная черта
  line,

  /// Зигзаг / волна (виброкомпенсаторы, сильфонные демпферы, антивибрационные клапаны)
  zigzag,

  /// Стрелка направления потока
  arrow,

  /// Круг шаровой пробки
  circle,

  /// Наклонное седло клапана
  slantedDisc,
}

/// Тип органа управления / штока в 2D УГО
enum ValveStemSymbolType {
  /// Без штока и привода (самодействующий, обратный, виброкомпенсатор)
  none,

  /// Шпиндель с маховиком/штурвалом (задвижка, вентиль)
  handwheel,

  /// Поворотный рычаг/рукоятка (шаровой кран, затвор)
  lever,

  /// Квадрат/прямоугольник с произвольным текстом ('Э', 'М', 'АВ', 'РД' и т.д.)
  boxWithText,

  /// Мембранный привод / грибок (МИМ)
  diaphragm,

  /// Пружинный колпак предохранительного клапана
  spring,
}
```

### 2.2 Модель параметров 2D УГО (`ValveSymbolConfig`)
```dart
class ValveSymbolConfig {
  final ValveWingFillStyle leftWingStyle;
  final ValveWingFillStyle rightWingStyle;
  final ValveDividerType dividerType;
  final ValveStemSymbolType stemType;
  final String stemText; // Буквенный маркер для boxWithText (напр. "Э", "АВ")
  final bool hasBodyFlanges; // Рисовать ли полоски фланцев на торцах УГО

  const ValveSymbolConfig({
    this.leftWingStyle = ValveWingFillStyle.outline,
    this.rightWingStyle = ValveWingFillStyle.outline,
    this.dividerType = ValveDividerType.none,
    this.stemType = ValveStemSymbolType.handwheel,
    this.stemText = 'Э',
    this.hasBodyFlanges = false,
  });
}
```

### 2.3 Модель параметров 3D тела (`ValveGeometry3dConfig`)
```dart
enum Valve3dBodyShape {
  /// Встречные усеченные конусы
  doubleCones,

  /// Цилиндрический бочонок
  cylinder,

  /// Цилиндрический бочонок с гофрой/кольцами (виброкомпенсатор, сильфон)

enum Valve3dActuatorType {
  /// Без штока и привода
  none,

  /// Шпиндель с круглым штурвалом и спицами
  handwheel,

  /// Г-образный рычаг
  lever,

class ValveGeometry3dConfig {
  final Valve3dBodyShape bodyShape;
  final Valve3dActuatorType actuatorType;
  final double stemHeightRatio; // Относительно радиуса трубы (по умолчанию 2.2)
  final double actuatorSizeRatio; // Относительно радиуса трубы (по умолчанию 1.4)

  const ValveGeometry3dConfig({
    this.bodyShape = Valve3dBodyShape.doubleCones,
    this.actuatorType = Valve3dActuatorType.handwheel,
    this.stemHeightRatio = 2.2,
    this.actuatorSizeRatio = 1.4,
  });
}
```

### 2.4 Паспорт пользовательского семейства (`CustomValveDefinition`)

class CustomValveDefinition {

  factory CustomValveDefinition.fromJson(Map<String, dynamic> json);

### 2.5 Интеграция в доменную модель `Valve`
В существующий класс [`Valve`](file:///d:/Git/Akso/lib/domain/models/valve.dart):
- Добавляется поле: `final String? customDefinitionId;`
- Расширяется метод определения строительной длины и наименования: если `customDefinitionId != null`, параметры считываются из каталога `CustomValveCatalog`.
- Полная обратная совместимость JSON: при отсутствии `customDefinitionId` используется стандартный `valveType`.

## 3. Отрисовка 2D УГО (`ValveSymbolPainter`)

Модуль `ValveSymbolPainter` расширяется для отрисовки по спецификации `ValveSymbolConfig`:
1. **Крылья корпуса:**
   - Отрисовка левого треугольника от $(-L/2, \pm H/2)$ до $(0, 0)$.
   - Отрисовка правого треугольника от $(0, 0)$ до $(L/2, \pm H/2)$.
   - Применение стилей:
     - `outline`: заливка белым непрозрачным фоном + контурная обводка.
     - `solid`: сплошная заливка цветом системы/арматуры (`strokePaint.color`).
     - `hatched`: заливка белым фоном + наложение отрезков под углом $45^\circ$ внутри контура треугольника (клиппирование через `canvas.clipPath`).
     - `crossHatched`: двойная штриховка под $\pm 45^\circ$.
2. **Центральный разделитель:**
   - `zigzag`: серия из 3-4 острых зубцов/волн в зоне сопряжения, образующих УГО сильфона/вибровставки.
   - `arrow`: стрелка потока.
   - `circle`: кружок пробки крана.
3. **Шток и привод:**
   - `boxWithText`: шток высотой $1.3 \times H$, квадрат $14 \times 14$ px с белым фоном и обводкой, внутри центрированный текст `stemText` шрифтом 9pt bold (например, **«Э»** для электропривода или **«АВ»** для антивибрационного).
   - `diaphragm`: шток + овальная уплощенная тарелка мембраны.
   - `spring`: вертикальный прямоугольник с диагональной линией пружины.

## 4. Отрисовка 3D Тела (`Element3dGeometry` и `Solid3dEngine`)

Генерация 3D Wireframe и твердотельных полигонов в локальном базисе трубы $(\vec{t}, \vec{u}, \vec{v})$:
1. **Корпус (`bodyShape`):**
   - `doubleCones`: усеченные конусы от входного и выходного колец к центру.
   - `cylinder`: гладкий цилиндр с образующими линиями.
   - `bellows`: цилиндрический корпус с серией выступающих тороидальных ребер/колец виброкомпенсатора.
   - `sphere`: фасетированная сфера в центре трубы.
2. **Привод (`actuatorType`):**
   - `actuatorBox`: на конце штока генерируется 3D параллелепипед редуктора электропривода + цилиндрический боковой мотор со штурвалом ручного дублера.
   - `diaphragm`: усеченный конус мембранной коробки в плоскости $\vec{u}, \vec{v}$.
   - `springBonnet`: цилиндрический стакан с крышкой.

## 5. UI: Интерактивный диалог конструктора (`CustomValveEditorDialog`)

Двухколоночный интерфейс:
- **Левая колонка (Панель параметров):**
  - Общие данные: Название, описание, базовая длина.
  - Секция 2D УГО:
    - Заливка левого крыла: чипы `[Контур]`, `[Сплошной]`, `[Штриховка]`.
    - Заливка правого крыла: чипы `[Контур]`, `[Сплошной]`, `[Штриховка]`.
    - Разделитель: чипы `[Нет]`, `[Линия]`, `[Зигзаг / Волна]`, `[Стрелка]`.
    - Привод: чипы `[Маховик]`, `[Рычаг]`, `[Квадрат с текстом]`, `[Мембрана]`, `[Пружина]`, `[Без привода]`.
    - Поле ввода текста привода (если выбран квадрат с текстом): `Э`, `АВ`, `М` и т.д.
  - Секция 3D:
    - Форма корпуса: `[Конусы]`, `[Цилиндр]`, `[Сильфон / Гофра]`, `[Шар]`.
    - Форма привода: `[Маховик]`, `[Электропривод]`, `[Мембрана МИМ]`, `[Пружина]`, `[Без штока]`.
- **Правая колонка (Живой предпросмотр в реальном времени):**
  - Верхняя карточка: крупный 2D-символ ГОСТ на белом поле с координатной сеткой.
  - Нижняя карточка: 3D-модель в изометрии на фрагменте трубы, которую можно поворачивать мышью!
- Кнопки: «Отмена», «Сохранить семейство».

## 6. Каталог и хранение (`CustomValveCatalog`)

- Хранение в `ApplicationDocumentsDirectory/custom_valves.json` (доступно во всех проектах пользователя) + встраивание определений в `ProjectModel` (для автономности файлов при передаче коллегам).
- Встроенные стартовые пресеты:
  1. *Клапан антивибрационный (виброкомпенсатор)* (зигзагообразная вставка, маркер «АВ», 3D bellows).
  2. *Задвижка с электроприводом* (квадрат «Э», 3D actuatorBox).
  3. *Регулятор давления прямого действия* (мембрана «М», импульс).
  4. *Клапан обратный поворотный с заливкой* (сплошной правый треугольник, стрелка).
