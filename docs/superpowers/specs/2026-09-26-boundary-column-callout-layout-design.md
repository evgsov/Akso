# Дизайн-спецификация: Интеллектуальная авторасстановка выносок без пересечений (Boundary Column Callout Layout)

**Статус:** Согласовано с пользователем / На ревью

## 1. Введение и постановка проблемы

### 1.1. Текущая ситуация
На реальных исполнительных схемах трубопроводов высокой плотности (50–100 выносок на листе формата А3, включая арматуру, фланцы, сварные стыки, переходы и опоры) существующий жадный радиальный алгоритм поиска («веер лучей во все стороны») приводит к образованию сплошной «паутины» (crisscross spiderweb). Линии-выноски пересекают друг друга под произвольными углами (от -165° до +165°), разрезают трубы и загромождают чертеж, делая его трудночитаемым и не соответствующим ГОСТ 2.316-2008 / ГОСТ 21.101.

### 1.2. Цели и критерии успеха
1. **0 самопересечений выносных линий:** Линии-выноски не должны пересекать друг друга.
2. **Структурированная колоночная компоновка (Boundary Column Stacking):** Выноски выстраиваются в вертикальные упорядоченные гребёнки (колонки) на свободных полях чертежа слева и справа от геометрии трубопроводов.
3. **Адаптивный динамический шаг полочек:** Полный отказ от захардкоженных шагов (никаких жестких 7 мм). Шаг полочек по вертикали $\Delta Y$ динамически рассчитывается на основе высоты шрифта (`textHeight`) и адаптируется к плотности элементов листа.
4. **Защита штампа и таблиц:** Правая колонка слотов не заходит на основную надпись Форма 3 (185×55 мм) и таблицы спецификаций.
5. **Сохранение ручной свободы:** Результат авторасстановки сохраняется в `sheetOffsets[sheetId]` конкретного листа, пользователь может в любой момент вручную подвинуть любую выноску.

## 2. Архитектура и математическая модель

### 2.1. Теорема непересекающегося граничного связывания (Planar Sweep-Line Matching)
В плоской геометрии (Boundary Labeling), если множество точек привязки (анкеров) $A = \{a_1, a_2, \dots, a_n\}$ расположено по одну сторону от вертикальной направляющей $X = X_{col}$, на которой размещены слоты полочек $S = \{s_1, s_2, \dots, s_n\}$, то при монотонном упорядочивании по вертикальной оси $Y$:
$$y(a_1) \le y(a_2) \le \dots \le y(a_n) \quad \text{и} \quad y(s_1) < y(s_2) < \dots < y(s_n)$$
отрезки линий-выносок $[a_i, s_i]$ и $[a_j, s_j]$ **математически гарантированно не пересекаются** при любых $i \neq j$.

```
 [Трубопроводная сеть]                          [Вертикальная колонка]
    a₁ (x₁, y₁) ─────────────────────────────── s₁ ─── [ Ф-5 ]
         \
          \
    a₂ (x₂, y₂) ─────────────────────────────── s₂ ─── [ К-12 ]   (Шаг ΔY адаптирован
               \                                                   к textHeight)
                \
    a₃ (x₃, y₃) ─────────────────────────────── s₃ ─── [ А-1 ]
```

## 3. Геометрическое зонирование листа

### 3.1. Определение Bounding Box сети
1. Все 3D-узлы и сегменты активных систем проецируются на плоскость бумаги листа в миллиметрах через `ViewportTransformService.model2dToSheetMm`.
2. Вычисляется охватывающий прямоугольник геометрии труб: $[X_{min}, Y_{min}, X_{max}, Y_{max}]$.
3. Разделительная ось сторон:
   $$X_{mid} = \frac{X_{min} + X_{max}}{2}$$
4. Выноски разделяются на две группы по положению их анкера:
   - **Левая группа ($G_L$):** $X_{anchor} \le X_{mid}$.
   - **Правая группа ($G_R$):** $X_{anchor} > X_{mid}$.

### 3.2. Направляющие колонок (X-координаты)
- **Левая направляющая ($X_{col\_L}$):**
  Располагается слева от геометрии труб:
  $$X_{col\_L} = \max(\text{frameLeft} + 22\text{ мм}, X_{min} - 28\text{ мм})$$
  Полочка выноски идет горизонтально вправо под текстом (или влево в сторону поля).
- **Правая направляющая ($X_{col\_R}$):**
  Располагается справа от геометрии труб:
  $$X_{col\_R} = \min(\text{frameRight} - 28\text{ мм}, X_{max} + 18\text{ мм})$$

### 3.3. Запретные зоны (Keepouts)
- Штамп по ГОСТ 21.101 (Форма 3): $185 \times 55$ мм в правом нижнем углу.
- Таблицы спецификации и журнала сварки: прямоугольники $T_k$.
- Для правой колонки $G_R$ эффективная нижняя граница размещения:
  $$Y_{bottom\_R} = \min\left(H_{sheet} - 55\text{ мм} - 5\text{ мм}, \min_{k}(T_k.y) - 5\text{ мм}\right)$$

## 4. Динамический адаптивный расчет шага полочек

### 4.1. Расчет базового и минимального шага
Пусть средняя высота шрифта выносок равна $h = \text{textHeight}$ (типовые значения 2.0, 2.5, 3.0, 3.5 мм):
- **Идеальный комфортный шаг:**
  $$\Delta Y_{ideal} = h \times 2.2$$
- **Абсолютный физический минимум читаемости:**
  $$\Delta Y_{min} = h + 1.2\text{ мм}$$

### 4.2. Адаптивное распределение (Adaptive Compaction)
Для группы из $N$ выносок на доступной высоте $H_{avail} = Y_{bottom} - Y_{top}$:
1. **Просторный режим ($N \times \Delta Y_{ideal} \le H_{avail}$):**
   - Используется комфортный шаг $\Delta Y_{ideal}$.
   - Блок полочек центрируется относительно средней $Y$-координаты анкеров группы, минимизируя наклон выносных линий (делая их максимально горизонтальными).
2. **Сжатый режим ($N \times \Delta Y_{min} \le H_{avail} < N \times \Delta Y_{ideal}$):**
   - Шаг плавно ужимается под доступную высоту:
     $$\Delta Y = \frac{H_{avail}}{N}$$
   - Сохраняется 1 ряд, все выноски аккуратно распределяются без перекрытий текста.
3. **Режим высокой плотности (Многорядность):**
   - Если даже при максимальном сжатии $N \times \Delta Y_{min} > H_{avail}$, колонка автоматически делится на **2 параллельных ряда**:
     - Внешний ряд (ближе к рамке листа).
     - Внутренний ряд (смещен на 28–32 мм ближе к трубам).
   - Выноски распределяются между рядами по $X$-глубине анкеров с сохранением монотонного $Y$-порядка внутри каждого ряда.

## 5. Обработка сверхплотных узлов (Coincident Anchors)

Когда в одном компактном узле (клапан + фланцы + стыки) сходятся несколько элементов с расстоянием между анкерами $< 4.0$ мм:
1. Элементы объединяются в виртуальный микрокластер.
2. Внутри кластера элементы сортируются по логическому приоритету УГО:
   $$\text{WeldJoint (К)} \;\to\; \text{Flange (Ф)} \;\to\; \text{Valve (А)} \;\to\; \text{Fitting} \;\to\; \text{Support}$$
3. В колонке выноски кластера получают последовательные слоты $s_k, s_{k+1}, s_{k+2}$ с текущим шагом $\Delta Y$.
4. Выносные линии расходятся из одной точки веером без пересечений.

## 6. Алгоритм трассировки и полочки (Leader & Shelf)

По ГОСТ 2.316-2008:
- **Линия-выноска:** прямой отрезок от анкера $(x_a, y_a)$ до начала горизонтальной полочки $(x_{col}, y_{slot})$.
- **Горизонтальная полочка:** отрезок длиной:
  $$L_{shelf} = \max(12.0\text{ мм}, \text{text.length} \times 0.65 \times h + 3.0\text{ мм})$$
  направленный горизонтально.
- **Хранение смещения:**
  $$\text{storedOffset} = \text{Offset}\left(\frac{x_{col} - x_a}{0.35}, \frac{y_{slot} - y_a}{0.35}\right)$$
  сохраняется в `callout.sheetOffsets[sheet.id]`.

  - `runSheetCalloutAutoLayout` бесшовно запускает новый расчет.

### 7.2. План тестирования (`test/callout_boundary_column_layout_test.dart`)
1. **0 Crossings Test:** тест со сложной сетью (80+ выносок), проверяющий, что ни один отрезок выноски не пересекает другой.
2. **Stamp Keepout Test:** проверка того, что ни одна полочка не попадает в прямоугольник штампа $185 \times 55$ мм и таблицы.
3. **Adaptive Pitch Test:** проверка шага $\Delta Y$ для шрифтов 2.0 мм, 2.5 мм и 3.5 мм.
4. **Frame Bounds Test:** все полочки строго внутри рабочей рамки чертежного листа.
5. **Static Analysis:** `flutter analyze` — 0 issues.
