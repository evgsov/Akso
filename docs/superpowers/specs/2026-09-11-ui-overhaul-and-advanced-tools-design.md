# Спецификация: Редизайн UI, адаптивные стили (Desktop / Tablet), расширенные инструменты трассировки и диспетчер систем

**Дата:** 2026-09-11  
**Проект:** Akso 3D  
**Статус:** Согласовано с пользователем  

---

## 1. Контекст и цели

Текущий интерфейс приложения страдает от перегруженности и неравномерного распределения элементов управления:
- Верхняя панель содержит разнородные элементы (проекции, каталоги, ведомости, экспорт).
- Нижняя панель занимает слишком много высоты холста, смешивая выбор инструментов, систем, диаметров и сталей.
- Отсутствует возможность отмены незавершенной операции черчения при случайном клике.
- Отсутствует система истории (Undo / Redo).
- Недостаточно наглядна объектная привязка (Snap) и навигация в пространстве (панорамирование, орбита).
- Невозможно полноценно создавать и настраивать пользовательские инженерные системы с сортаментом диаметров и маркой стали (по аналогии с Revit).
- Конструктор фитингов («Создать на основе...») не позволял выбирать базовый прототип, клонируя только первый отвод.

### Цели спецификации:
1. Реализовать **два режима компоновки интерфейса**:
   - **`Desktop CAD`:** профессиональный САПР-интерфейс с левым вертикальным тулбаром, контекстным баром параметров, строкой состояния, поддержкой мыши (СКМ/ПКМ) и хоткеев.
   - **`Tablet Touch`:** сенсорный стиль для планшета со стилусом с чистым холстом, плавающим островом инструментов и увеличенными областями нажатия ($48\times48$ pt).
2. Реализовать **прерывание черчения** (`Esc`, ПКМ, экранная кнопка «Отмена»).
3. Реализовать стек **Undo / Redo** (`Ctrl+Z`, `Ctrl+Y`) с менеджером истории `NetworkHistoryManager`.
4. Реализовать **объектные привязки (SnapEngine)** и полноценную навигацию (Pan, Orbit, Zoom).
5. Реализовать **полярную угловую привязку** ($30^\circ, 45^\circ, 90^\circ$, индивидуальный угол, свободный).
6. Реализовать **строительные оси и вспомогательные линии** с марками в кружках по ГОСТ 21.101 и экспортом в DXF (`АКСО_ОСИ`).
7. Реализовать **Диспетчер систем трубопроводов** (код, имя, цвет, марка стали, допустимые диаметры, правила трассировки).
8. Усовершенствовать диалог **«Создать на основе...»** с селектором любого элемента каталога.

## 2. Архитектура UI и стили компоновки

### 2.1 Переключатель режима (`UiLayoutMode`)
```dart
enum UiLayoutMode {
  desktopCad,
  tabletTouch,
  auto,
}
```
* Переключение через кнопку в шапке («🖥️ Десктоп / 📱 Планшет») с сохранением предпочтения.

### 2.2 Десктопный CAD-стиль (`DesktopCadLayout`)
* **Шапка (Header):**
  - Логотип Akso + Название схемы.
  - Кнопки `Undo` (Ctrl+Z) / `Redo` (Ctrl+Y).
  - Компактный выбор проекций (ГОСТ 45°, Зеркало, ISO 30°, 3D Орбита, План 2D).
  - Кнопки менеджеров: «Системы» (с цветовым бейджем), «Каталог фитингов», меню «Ведомости» (Журнал, Катушки, СО), кнопка «Экспорт DXF».
* **Левый вертикальный тулбар (Tool Palette):**
  - Группы: Навигация (`Выбор`, `Панорама`, `3D Орбита`), Построение (`Трассировка`, `Стояк`, `Строительная ось`), Врезка (`Арматура`, `Сварка`, `Переход`, `Фланец`).
* **Контекстный Options Bar (сверху под шапкой):**
  - При `Трассировке`: Селектор системы, диаметр Ду, марка стали, тумблер «Тройник / Врезка У18», режим углов ($90^\circ, 45^\circ, 30^\circ$, Custom), кнопка **«Отмена (Esc)»**.
* **Нижняя строка состояния (Status Bar):**
  - Координаты курсора: `X: ... мм  Y: ... мм  Z: ... мм`.
  - Статус привязки: `[SNAP: ВКЛ]`.
  - Контекстная подсказка по действию и горячим клавишам.
* **Правый плавающий инспектор свойств:**
  - Карточка свойств при выборе узла/сегмента (габариты, диаметр, отметка, сталь, кнопка удаления).

### 2.3 Планшетный сенсорный стиль (`TabletTouchLayout`)
* **Минималистичная верхняя полоса:** текущий вид, активная система, кнопка меню [≡] и переключатель режима.
* **Плавающий остров инструментов (Floating Tool Island):**
  - Вертикальная или нижняя пилюля с крупными круглыми кнопками ($48\times48$ pt).
* **Плавающая командная панель справа:**
  - Кнопки `Undo`, `Redo`, `Отмена`, `Свойства`, `Высотные отметки`.
* **Выдвижная нижняя шторка параметров:**
  - Настройка параметров активного инструмента, не загораживающая обзор чертежа.

## 3. Отмена действий и стек Undo / Redo

### 3.1 Модель истории (`NetworkHistoryManager`)
* Хранит циклический стек снимков состояния `PipingNetwork` (до 50 состояний).
* `recordState(PipingNetwork network)` вызывается перед каждым модифицирующим действием.
* `undo() -> bool` и `redo() -> bool` восстанавливают состояние и вызывают пересчет катушек `recalculateSpools()`.
* Флаги `canUndo` и `canRedo` управляют активностью кнопок.

### 3.2 Отмена операции (`cancelCurrentOperation()`)
* Если `traceStartNode != null`: очищает `traceStartNode`, `currentCursorScreenPos = null`.
* Снимает активное выделение узлов и сегментов.
* При повторном вызове сбрасывает инструмент в `CanvasTool.select`.
* Обработка: клавиша `Esc`, клик ПКМ, экранная кнопка «Отмена».

## 4. Объектные привязки и навигация 3D/2D

### 4.1 Движок привязок (`SnapEngine`)
* Типы привязок:
  - `node`: захват узла сети в радиусе 22 px (маркер: зеленый ромб + отметка $\nabla Z$).
  - `segmentAxis`: захват оси трубы в радиусе 18 px (маркер: бирюзовый крестик + подпись «Врезка Ду...»).
  - `gridAxis`: захват строительной оси здания (маркер: желтый маркер оси).
  - `intersection`: пересечение осей или труб (маркер: янтарный крест).
* При наведении курсор визуально примагничивается к цели, гарантируя 100% точность соединения без случайных разрывов.

### 4.2 Навигация
* **Колесико мыши (Scroll):** Зум к курсору.
* **Средняя кнопка мыши (СКМ / MMB drag):** Панорамирование в любом режиме инструмента.
* **Пробел + ЛКМ drag:** Альтернативное панорамирование для ноутбуков.
* **Правая кнопка мыши (ПКМ drag):** 3D-орбита (в 3D-режиме) или отмена/контекстное меню (в 2D).
* **Мультитач (Touch):** 2 пальца = Pan + Zoom, 1 палец/стилус = текущий инструмент.
* **Инструмент «Рука» (PanTool):** выделенный режим панорамирования для стилуса.

## 5. Полярное отслеживание и угловые шаги

### 5.1 Режимы угловой фиксации (`AngleSnapMode`)
```dart
enum AngleSnapMode {
  ortho90,      // 0°, 90°, 180°, 270°
  isometric45,  // шаг 45°
  iso30,        // шаг 30°
  custom,       // пользовательский угол (например, 15°)
  free,         // без привязки
}
```
* При движении курсора рассчитывается угол от `traceStartNode`:
  $$\theta = \text{atan2}(\Delta Y, \Delta X)$$
* При отклонении менее $\pm 5^\circ$ от ближайшего разрешенного луча срабатывает захват.
* Отрисовывается пунктирный направляющий луч и HUD-бейдж: `L: ... мм | ∠...°`.

## 6. Строительные оси и вспомогательные направляющие

### 6.1 Модель данных (`ConstructionAxis`)
```dart
class ConstructionAxis {
  final String id;
  final String label; // "1", "2", "А", "Б"
  final Node3D startPoint;
  final Node3D endPoint;
  final bool isBuildingGrid; // true = ось здания с кружками, false = вспомогательная линия
}
```
* Отрисовка: штрихпунктирная линия по ГОСТ 2.303, кружки марок осей на концах с буквами/цифрами.
* Экспорт в AutoCAD DXF: слой `АКСО_ОСИ` (тип линии `DASHDOT`, окружности и текст).

## 7. Диспетчер инженерных систем (Revit-style)

### 7.1 Расширение `PipingSystem`
* `defaultMaterial: String` — марка стали по умолчанию.
* `availableDns: List<int>` — список разрешенных диаметров.
* `defaultElbowId: String?`, `defaultBranchId: String?`, `defaultFlangeId: String?`.
* `isCustom: bool` — возможность создания, редактирования и удаления систем.

### 7.2 Интерфейс «Диспетчер систем»
* Список всех систем с цветовыми индикаторами.
* Форма редактирования/создания системы: задание кода (ТХ1, В2, П1), названия, выбор цвета из палитры, назначение стали и диаметров.
* Быстрый выбор активной системы в один клик.

---

## 8. Конструктор фитингов («Создать на основе...»)

* Диалог создания пользовательского элемента оснащается **селектором базового элемента-прототипа**.
* Выбор любого стандартного или пользовательского элемента из каталога мгновенно подгружает его параметры в поля ввода.
* Кнопка «Клонировать» в каждой строке каталога для мгновенного дублирования.
