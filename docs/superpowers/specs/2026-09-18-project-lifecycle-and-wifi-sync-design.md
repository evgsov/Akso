# Дизайн-спецификация: Управление проектами и локальный Wi-Fi мост обмена (ПК ↔ Планшет)

## 1. Обзор и цели (Overview & Goals)

Цель данной подсистемы — обеспечить профессиональный, надежный и удобный жизненный цикл проекта в Akso на всех целевых платформах (Windows Desktop, Android-планшеты, iOS, Web), а также реализовать мгновенный локальный обмен проектами между компьютером и планшетом без необходимости использования облачных сервисов или проводов.

### Ключевые цели:
1. **Надежное сохранение и открытие файлов проекта (`.akso`):**
   - Устранение дефекта `FilePicker` на Desktop (когда байты не записывались на диск по выбранному пути).
   - Разделение команд: «Новый проект» (`Ctrl+N`), «Открыть...» (`Ctrl+O`), «Сохранить» (`Ctrl+S`), «Сохранить как...» (`Ctrl+Shift+S`).
   - Запоминание пути текущего файла (`currentFilePath`): повторное нажатие `Ctrl+S` сохраняет проект мгновенно без вызова диалога проводника.
   - Отслеживание несохраненных изменений (`hasUnsavedChanges`) с индикатором `*` в заголовке и предупреждением при попытке создать новый проект или открыть другой без сохранения.
2. **Список «Недавние проекты» (Recent Projects):**
   - Сохранение истории открывавшихся файлов (название, путь, дата последнего доступа) в локальном хранилище (`SharedPreferences` / JSON-конфиг).
   - Быстрый доступ к последним проектам из меню тулбара в 1 клик с валидацией существования файла на диске.
3. **Карточка метаданных «Свойства проекта»:**
   - Диалог просмотра и редактирования: Название проекта, Шифр/Марка, Наименование объекта/адрес, Ответственный инженер-проектировщик, Дата создания, Заметки.
4. **Быстрый локальный обмен «ПК ↔ Планшет» (Akso QuickBridge):**
   - Автономная передача проекта в один клик по локальной сети Wi-Fi (или мобильной точке доступа со смартфона) без интернета и регистрации.
   - Встроенный микросервер на `dart:io` `HttpServer` с UDP-маяком (автообнаружение устройств в локальной сети) и QR-кодом для планшета.
   - Защита сессии одноразовым 4-значным PIN-кодом / токеном передачи.
   - Двусторонняя синхронизация: ПК → Планшет (перед выходом на объект) и Планшет → ПК (по возвращении с объекта для оформления DXF).
5. **Системная передача (Fallback Share):**
   - Кнопка «Поделиться проектом» через системный `SharePlus` (отправка `.akso` в Telegram, почту, диск или проводник).

## 3. Файловый репозиторий проектов (`ProjectRepository`)

Файл `lib/data/repositories/project_repository.dart`:
1. **`saveProjectToFile(ProjectModel project, {String? targetPath})`:**
   - Если `targetPath` передан — производит прямую атомарную запись байтов `File(targetPath).writeAsString(jsonString)`.
   - Если `targetPath == null` — вызывает системный `FilePicker.platform.saveFile(...)`, получает путь от пользователя, гарантирует добавление расширения `.akso`, производит фактическую запись файла на диск и возвращает итоговый путь `String`.
2. **`openProjectFromFile({String? filePath})`:**
   - Если `filePath` передан — напрямую читает `File(filePath).readAsString()`, парсит JSON и возвращает `ProjectModel`.
   - Если `filePath == null` — вызывает `FilePicker.platform.pickFiles(type: FileType.custom, allowedExtensions: ['akso'])`, считывает байты и возвращает загруженный проект вместе с его путем.
3. **Обработка ошибок:**
   - Перехват поврежденных JSON-файлов (`FormatException`), вывод понятного русскоязычного сообщения в UI.

## 4. Локальный Wi-Fi мост обмена (Akso QuickBridge)

Файл `lib/data/services/quick_bridge_service.dart`:

### 4.1. Принцип работы (P2P без внешнего интернета)
```
[ ПК (Редактор Akso) ]                      [ Планшет (Полевой Akso) ]
        |                                              |
 1. Нажать «Передать на планшет»                       |
    -> Запуск HttpServer (:41234)                     |
    -> Определение локального IP (192.168.x.x)         |
    -> Генерация PIN (например, 7429)                 |
    -> Старт UDP-маяка (broadcast port 41235)          |
    -> Отображение окна с QR-кодом и PIN               |
        |                                              |
        |  <-------- UDP Beacon / Поиск ПК ----------  |  2. Нажать «Принять с ПК»
        |  ------- Найдено: "ПК-Инженер" (IP, PIN) ->  |     (или навести камеру на QR)
        |                                              |
        |  <-- HTTP GET /sync?pin=7429 --------------- |  3. Запрос передачи проекта
        |  --- HTTP 200 OK + JSON проекта -----------> |  4. Получение проекта
        |                                              |  5. Проект открыт на планшете!
 6. Закрытие сервера                                   |
```

### 4.2. Безопасность и надежность:
- Сервер открывается только по явному требованию пользователя и слушает локальную подсеть.
- Автоматический таймаут: если передача не состоялась в течение 3 минут, сервер останавливается.
- Одноразовый 4-значный PIN-код и токен сессии предотвращают несанкционированное скачивание.
- Обратная передача (Планшет → ПК): при нажатии «Отправить на ПК» на планшете отправляется HTTP POST `/upload`, а на ПК появляется диалоговое окно: *«Получен обновленный проект с планшета (Цех №3). Загрузить в редактор?»*.

## 5. Пользовательский интерфейс (UI & UX)

### 5.1. Верхняя панель (TopBar & DesktopCadLayout)
1. **Индикатор проекта:**
   - Отображение: `AKSO 3D — [Новый проект.akso *]` (звездочка `*` при несохраненных изменениях).
   - Клик по названию открывает диалог **«Свойства проекта»**.
2. **Группа кнопок управления проектом:**
   - **«Создать» (`Ctrl+N`):** создание чистого проекта с проверкой несохраненных правок.
   - **«Открыть» (`Ctrl+O`):** выпадающее меню:
     - *«Выбрать файл на диске...»*
     - Разделитель
     - Список недавних проектов (до 5 позиций) с датой и быстрым открытием.
   - **«Сохранить» (`Ctrl+S`):** быстрое сохранение в текущий файл или вызов «Сохранить как...», если файл новый.
   - **«Сохранить как...» (`Ctrl+Shift+S`):** принудительный выбор пути и имени.
   - **«Быстрый обмен (Wi-Fi)»:** кнопка со значком планшета/Wi-Fi:
     - Открывает диалог с QR-кодом, локальным IP, PIN-кодом и кнопкой переключения режима (Отдать / Принять).
   - **«Поделиться файлом»:** системный диалог `share_plus`.

### 5.2. Диалог «Свойства проекта» (`ProjectPropertiesDialog`)
Поля ввода:
- Наименование проекта (обязательное).
- Шифр проекта / Марка комплекта (например: `01-2026-ТХ`).
- Наименование объекта / Адрес строительства.
- Инженер-проектировщик.
- Дата создания и последнего изменения (только чтение).
- Текстовые заметки / примечания к чертежу.

### 5.3. Диалог быстрого обмена («Akso QuickBridge»)
- Индикатор локальной сети (подключен к Wi-Fi: `IP 192.168.1.105`).
- Крупный QR-код и 4-значный цифровой PIN.
- Список автоматически обнаруженных устройств Akso в сети.
- Анимация успешной передачи и кнопка закрытия.
